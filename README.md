# Aim Trainer Game Project

## Project Description

My project is going to be an aim trainer like game where you have to click as many objects as you can in a certain timeframe, or get to a certain score in the least amount of time possible.

This application might be used by people who want to improve their aim for games like Valorant and CS:GO, people who want to test how good their aim is, or people who just want play a quick game.

This project interests me because I want to make some sort of game, but I don't want it to be too complicated like recreating Undertale. I actually don't even play any first person shooter games like Valorant and CS:GO, so I'm not doing this project because of those games specifically--as I mentioned before, moreso because I want to make some sort of game.

## User Stories:
- As a user, I want to be able to increase the number of clickable objects in the current game so multiple can exist at a time.
- As a user, I want to be able to view a list of my past games and their respective scores.
- As a user, I want to be able to immediately start a new game once the current game is over.
- As a user, I want to be able to adjust the game parameters to my liking (like the amount of time each game lasts).
