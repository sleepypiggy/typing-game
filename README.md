# Typing Game

## A simple typing game made with Java and the Swing framework.

It's sightly different from most other ones as there is no real-time character matching indication. Only at the end will you be able to see which character(s) you missed (that means even one missed or extra character will displace and therefore mismatch the rest after).

## Features
- Accuracy checker.
- WPM calculator.
- Timed rounds.
- Number of correct vs. incorrect characters.
- Save favourite phrases to file.
- Load favourite phrases from file.
- Add custom phrases.
- SFX.
- Background music.

## Technologies Used
- Java, Swing, JUnit, Maven.
